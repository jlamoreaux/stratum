## Common issues

### 401 Unauthorized

- Check your token is valid
- Ensure Authorization header is set

### 404 Not Found

- Verify project namespace and slug
- Check project exists

### Import fails

- Check GitHub URL is correct
- For private repos, provide token
- Wait and retry
